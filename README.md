# AerialNav — навигация БПЛА без GPS по визуальным реперам

Система визуальной навигации беспилотного летательного аппарата (БПЛА) в условиях
отсутствия или подавления сигнала GPS. Навигация осуществляется путём сопоставления
кадров бортовой камеры с предварительно загруженной картой подстилающей поверхности
с помощью сиамской нейронной сети.

## Постановка задачи

БПЛА типа «крыло» (CUAV X7+ Pro) выполняет маршрутное задание на высоте 700–1000 м.
При потере GPS-сигнала (спуфинг, глушение, отказ приёмника) дрон должен продолжить
следование по маршруту, опираясь на:

- **Бортовую камеру** OpenIPC MC800S-V3 (Sony IMX415, 4K, объектив ASX-0116 KH) — кадры подстилающей поверхности
- **IMU** (6 DOF) — оценку скорости и курса
- **Предварительно загруженную карту** маршрута (спутниковые снимки, 0.5 м/px)

## Рабочий процесс

### 1. Планирование маршрута

Веб-интерфейс (`web_route_planner/`) позволяет:
- Выбирать точки маршрута кликом по карте
- Импортировать маршрут из ссылки Яндекс.Карт
- Прокладывать маршрут по дорожной сети (OSRM API)
- Выбирать поставщика спутниковых тайлов (ESRI, OSM, Google, Yandex)
- Настраивать ширину полосы съёмки и размер квадрата у точек
- Оценивать количество тайлов и длину маршрута
- Запускать скачивание карты с прогресс-баром по каждому этапу

```bash
python web_route_planner/app.py
# Открыть http://localhost:8080
```

### 2. Подготовка данных

```bash
# Склейка тайлов в GeoTIFF
python stitch_map.py \
  --tiles map_cache/strips \
  --output map_cache/antiuav_route_strip.tif \
  --resolution 0.5

# Генерация координат тайлов (с фильтром однородных участков)
python generate_coords.py \
  --map map_cache/antiuav_route_strip.tif \
  --output training_data/route_dataset \
  --tile-size 512 --stride 256 --min-std 10.0
```

### 3. Обучение сиамской сети

```bash
python train_route_final.py
```

Модель: ResNet-18 backbone с GroupNorm (вместо BatchNorm для стабильности
при малом batch size), projection head 256D, L2-нормализация embeddings.
Loss: Contrastive Loss (margin=1.0).

### 4. Тест навигации

```bash
python test_route_dnepr.py
```

## Ключевые технические решения

### GroupNorm вместо BatchNorm
BatchNorm в `eval()` режиме даёт collapse embeddings при обучении с малым batch
и mixed precision — running statistics расходятся с batch statistics.
GroupNorm не зависит от batch size и работает одинаково в `train()` и `eval()`.

### Ленивое открытие rasterio в DataLoader workers
При `multiprocessing.set_start_method('fork')` общий файловый дескриптор
rasterio ломает чтение тайлов. Каждый воркер открывает собственный дескриптор
через `_ensure_src()` в `__getitem__`.

### Фильтрация однородных тайлов
Спутниковые тайлы вдоль маршрута могут быть визуально однородными (вода, поля).
Фильтр по `std` непустых пикселей (`--min-std`) отбрасывает тайлы без деталей,
оставляя только тайлы с дорогами, застройкой, растительностью.

### Выбор поставщика тайлов
ESRI World Imagery на zoom 19 в некоторых регионах отдаёт тайлы низкого
качества (2.5 КБ, однородный фон). Google Satellite даёт реальные снимки
(6 КБ, std=14–22). Выбор поставщика критичен для качества обучения.

## Технологии

- **Python 3.14**, PyTorch 2.11 (CUDA 12.8)
- **rasterio** — чтение GeoTIFF по окнам (без загрузки в RAM)
- **Flask** — веб-интерфейс планирования маршрута
- **Leaflet.js** — интерактивная карта
- **OSRM** — маршрутизация по дорожной сети
- **PIL/Pillow** — обработка изображений
- **ROS 2** — интеграция с полётным контроллером
